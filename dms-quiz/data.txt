### 第1章：ITインフラ・基礎知識編（デジタルの土台）

**Q1. Webサイトの通信を暗号化し、第三者による盗聴を防ぐ仕組み（URLがhttpsで始まるもの）は？**

1. SEO対策
2. SSL/TLS通信
3. DNSルーティング
4. FTP転送
【正解】2
**【解説】** 個人情報やパスワードを安全に送受信するための必須技術です。

**Q2. 複数のシステムを、1つのIDとパスワードでログインして利用できる仕組みは？**

1. VPN（仮想専用線）
2. 二段階認証（2FA）
3. エンドツーエンド暗号化（E2EE）
4. シングルサインオン（SSO）
【正解】4
**【解説】** 利便性とセキュリティを両立させる仕組みで、社内システムなどで導入が進んでいます。

**Q3. スマホやPCなど、端末の画面サイズに合わせてレイアウトが自動で最適化される手法は？**

1. レスポンシブデザイン
2. パララックスデザイン
3. フラットデザイン
4. アクセシビリティ
【正解】1
**【解説】** デバイスごとに別々のサイトを作らず、一つのサイトで表示を切り替えます。

**Q4. インターネット上の機器を識別するために割り当てられる「ネットワーク上の住所」は？**

1. MACアドレス
2. IPアドレス
3. ドメイン名
4. サブネットマスク
【正解】2
**【解説】** 通信を行う全ての機器が持つ一意の番号です。

**Q5. 次回訪問時の表示を高速化するために、ブラウザがデータを一時的に保存する仕組みは？**

1. Cookie
2. アーカイブ
3. キャッシュ
4. バックアップ
【正解】3
**【解説】** 2回目以降の表示を早めますが、古い情報が残ってしまう原因にもなります。

**Q6. テレワーク先などから安全に社内システムへ接続するための仮想専用線技術は？**

1. VPN
2. FTP
3. DNS
4. LAN
【正解】1
**【解説】** 公衆回線の中に専用の「トンネル」を作るイメージで通信を保護します。

**Q7. パソコンやスマホの土台となる「基本ソフトウェア（WindowsやiOSなど）」の総称は？**

1. ブラウザ（Web閲覧ソフト）
2. ミドルウェア（OSとアプリの中間層）
3. アンチウイルス（ウイルス対策ソフト）
4. OS（オペレーティングシステム）
【正解】4
**【解説】** あらゆるアプリケーションを動かすための最も基礎となるソフトです。

**Q8. ブラウザ等に後から便利な機能を追加するための小さなプログラムの総称は？**

1. ドライバ（機器制御ソフト）
2. パッチ（修正プログラム）
3. プラグイン（拡張機能）
4. ファームウェア（機器内蔵プログラム）
【正解】3
**【解説】** 自分の使い勝手に合わせてツールをカスタマイズできます。

**Q9. ネット経由でソフトウェアの機能を月額課金などで利用する形態（Zoom等）は？**

1. SaaS（サース）
2. オンプレミス（自社運用）
3. ローカルホスト（自端末内）
4. イントラネット（社内ネット）
【正解】1
**【解説】** ソフトウェアを「購入」するのではなく「利用」する、現在の主流です。

**Q10. ウイルスなど、デバイスに悪意のある動作をさせるソフトウェアの総称は？**

1. スパム
2. ファイアウォール
3. トラッキング
4. マルウェア
【正解】4
**【解説】** コンピュータウイルスやスパイウェアなどの総称です。

### 第2章：Web制作・マーケティング編（現場で使う用語）

**Q11. デザイン作業の前に作成する、画面のレイアウトやボタン配置を決めた「設計図」は？**

1. モックアップ
2. プロトタイプ
3. ワイヤーフレーム
4. サイトマップ
【正解】3
**【解説】** 色や写真を省き、要素の配置と機能だけを示す簡易図。デザイン作業前の認識合わせに使います。

**Q12. 専門知識がなくても、管理画面からテキストを登録してWebサイトを更新できるシステムは？**

1. CRM（顧客管理システム）
2. MA（マーケティング自動化）
3. SFA（営業支援システム）
4. CMS（コンテンツ管理システム）
【正解】4
**【解説】** WordPressが代表例。専門知識なしで更新できるため、企業サイトやブログで広く使われています。

**Q13. ユーザーが目にする画面の「見た目や操作性」を指す用語は？**

1. UI（ユーザーインターフェース）
2. UX（ユーザーエクスペリエンス）
3. CX（カスタマーエクスペリエンス）
4. DX（デジタルトランスフォーメーション）
【正解】1
**【解説】** ユーザーが直接触れる「見た目」と「操作性」の総称。直感的で迷わない設計が良いUIです。

**Q14. ユーザーがサービスを利用して得られる「体験や満足度」の総称は？**

1. UI（ユーザーインターフェース）
2. PV（ページビュー）
3. CV（コンバージョン）
4. UX（ユーザーエクスペリエンス）
【正解】4
**【解説】** サイト訪問前から利用後まで含む「体験全体」。UIはUXの一部分にあたります。

**Q15. ユーザーの入力内容や訪問履歴を、ブラウザに一時的に保存させる仕組み（ファイル）は？**

1. セッション（接続単位）
2. Cookie（クッキー）
3. キャッシュ（一時保存）
4. トークン（認証情報）
【正解】2
**【解説】** ログイン状態保持や閲覧履歴記録に使用。近年プライバシー規制（GDPR等）の対象です。

**Q16. Webページの「構造」を定義するHTMLに対し、「装飾」を指定する言語は？**

1. CSS
2. Java
3. PHP
4. SQL
【正解】1
**【解説】** 文字色・サイズ・余白・配置などを指定する言語。HTMLが「骨組み」ならCSSは「服装」です。

**Q17. 広告のリンク先となるページ（LP）を改善し、お問い合わせ率を高める施策は？**

1. SEO（検索エンジン最適化）
2. EFO（入力フォーム最適化）
3. LPO（ランディングページ最適化）
4. CRO（コンバージョン率最適化）
【正解】3
**【解説】** 見出し・CTA・フォームの改善などで、LPの離脱率改善やCV率向上を目指します。

**Q18. 商品購入や問い合わせなど、Webサイトにおける「最終的な成果」を指す言葉は？**

1. インプレッション（表示回数）
2. クリック（押下数）
3. コンバージョン（CV）
4. リーチ（到達人数）
【正解】3
**【解説】** サイト目的に応じた成果（購入・登録・問い合わせなど）。広告効果測定の最重要指標です。

**Q19. 1つの商品を売ることに特化した、縦長のWebサイトを何と呼ぶか？**

1. コーポレートサイト（企業サイト）
2. LP（ランディングページ）
3. ポータルサイト（玄関口サイト）
4. ECサイト（通販サイト）
【正解】2
**【解説】** 1商品・1サービスに絞った縦長の専用ページ。広告のクリック先として使われます。

**Q20. 検索結果で自社サイトを上位（目立つ場所）に表示させるための改善施策は？**

1. SEO（検索エンジン最適化）

3. MEO（マップ検索最適化）
4. LPO（ランディングページ最適化）
【正解】1

### 第3章：広告・分析編（数字を読み解く）

**Q21. 広告がユーザーの画面に「表示された回数」を示す指標は？**

1. リーチ（到達人数）
2. クリック（押下数）
3. インプレッション（IMP）
4. エンゲージメント（接触反応）
【正解】3
**【解説】** 「表示された回数」を示すため、同じ人に複数回表示されてもカウントされます。

**Q22. 広告を見た人のうち、実際にクリックした人の割合を示す指標は？**

1. CTR（クリック率）
2. CVR（コンバージョン率）
3. CPC（クリック単価）
4. CPA（顧客獲得単価）
【正解】1
**【解説】** 「Click Through Rate」の略。低い場合は広告クリエイティブの見直しが必要です。

**Q23. 1回のコンバージョンを獲得するのにかかった広告費用のことは？**

1. CPC（クリック単価）
2. CPA（顧客獲得単価）
3. CPM（インプレッション単価）
4. ROAS（広告費用対効果）
【正解】2
**【解説】** 「Cost Per Acquisition」の略。広告効率の指標で、低いほど良いとされます。

**Q24. 検索したキーワードに連動して検索結果の上部に出るテキスト広告は？**

1. ディスプレイ広告
2. 動画広告
3. リスティング広告
4. SNS広告
【正解】3
**【解説】** ユーザーの検索意図に直結するため、CV率が高い広告手法です。

**Q25. 一度サイトに来たユーザーを、別のサイトでも追いかけて表示する広告は？**

1. リスティング広告
2. アフィリエイト広告
3. ネイティブ広告
4. リターゲティング広告
【正解】4
**【解説】** 一度興味を示したユーザーへの再アプローチで、CV率向上を狙います。

**Q26. サイトを訪問したユーザーが、1ページ目だけを見て帰ってしまった割合は？**

1. 離脱率
2. 直帰率
3. 回遊率
4. クリック率
【正解】2
**【解説】** 高すぎる場合はLPの内容や速度に問題がある可能性。コンテンツ改善のヒントになります。

**Q27. サイト内のページが見られた「延べ回数」を指す指標は？**

1. UU（ユニークユーザー）
2. セッション（訪問単位）
3. PV（ページビュー）
4. リーチ（到達人数）
【正解】3
**【解説】** 同じユーザーが複数ページを閲覧すれば加算。サイト全体の活発さを示します。

**Q28. 投資した広告費に対して、どれだけの「売上」を得られたかを示す指標は？**

1. ROI（投資利益率）
2. CPA（顧客獲得単価）
3. LTV（顧客生涯価値）
4. ROAS（広告費用対効果）
【正解】4
**【解説】** 「Return On Ad Spend」の略。100%以上で広告投資が回収できている状態です。

**Q29. 2種類のデザインを同時に配信し、どちらが成果が出るか比較する検証は？**

1. ストレステスト
2. ユーザビリティテスト
3. A/Bテスト
4. 単体テスト
【正解】3
**【解説】** 客観的データで意思決定するための基本手法。LPやメール配信などで活用されます。

**Q30. 最終目標達成のための「中間目標（チェックポイント）」となる数値は？**

1. KGI（重要目標達成指標）
2. KPI（重要業績評価指標）
3. OKR（目標と主要成果）
4. MBO（目標管理制度）
【正解】2
**【解説】** 「Key Performance Indicator」の略。日々の業務改善のためのモニタリング指標です。

**Q49. Antigravityのようなツールで、異なる特徴を持つ複数のAI（Pro系やFlash系など）を切り替えて使う主な理由はどれか？**

1. 処理速度、回答精度、利用コスト（トークン）のバランスを最適化するため
2. 1つのAIでは1時間に1回しか質問ができないという制限があるため
3. AIごとに対応している言語（日本語のみ、英語のみ等）が厳密に分かれているため
4. パソコンのメーカー（AppleかMicrosoftか）によって使えるAIが異なるため
【正解】1
**【解説】** 高精度モデルは高コスト、軽量モデルは低コスト。用途に応じた使い分けが重要です。

**Q50. 生成AIが作成した文章を社外資料に活用する際、品質管理の観点で「最も重要」とされるプロセスはどれか？**

1. AIにさらに長い文章を書かせて情報を増やすこと
2. 別の複数のAIに同じ質問をして、回答を多数決で決めること
3. 印刷して、フォントの見た目が綺麗かどうかを確認すること
4. 内容に誤りがないか、人間の目による事実確認と校正を行うこと
【正解】4
**【解説】** AIは事実誤認や偏った回答を生成する可能性があり、最終確認は必ず人間が行うべきです。
