### 第1章：ITインフラ・基礎知識編（デジタルの土台）

**Q1. 1台のサーバー上に複数の独立した実行環境を作る、軽量な仮想化技術の代表は？**

1. 仮想マシン（VM）
2. コンテナ（Docker等）
3. エミュレータ
4. シミュレータ
【正解】2
**【解説】** OS全体を再現する仮想マシンより起動が高速で、クラウド時代のアプリ配備の標準手法になっています。

**Q2. 不正な通信を遮断し、社内ネットワークを守る「防火壁」の役割を担う仕組みは？**

1. ファイアウォール
2. ルーター
3. スイッチ
4. ハブ
【正解】1
**【解説】** 内部と外部の境界で通信を監視・制御し、不正アクセスや不審なデータ送受信を防ぐ基本的な防御装置です。

**Q3. IDとパスワードに加え、SMSや認証アプリのコードでも本人確認する追加認証の総称は？**

1. シングルサインオン（SSO）
2. 二要素認証（多要素認証）
3. ゼロトラスト（常時検証型防御）
4. パスキー（FIDO準拠）
【正解】2
**【解説】** 「知っているもの（パスワード）」と「持っているもの（スマホ）」を組み合わせ、パスワードが漏れても突破されにくくします。

**Q4. AWSやAzureが提供する「サーバーやストレージなどインフラ自体」を借りるクラウド形態は？**

1. SaaS（ソフトウェア・アズ・ア・サービス）
2. PaaS（プラットフォーム・アズ・ア・サービス）
3. IaaS（インフラ・アズ・ア・サービス）
4. BaaS（バックエンド・アズ・ア・サービス）
【正解】3
**【解説】** OSやミドルウェアは利用者側で構築する、最も自由度の高いクラウド形態。サーバー機器の購入・維持費を削減できます。

**Q5. データ消失や障害に備え、別の場所に複製を保管しておく作業は？**

1. アーカイブ
2. リストア
3. レプリケーション
4. バックアップ
【正解】4
**【解説】** ランサムウェア被害や機器故障時にデータを復旧できる「最後の砦」。世代管理と保管場所の分散がポイントです。

**Q6. 大量のサーバーや通信機器をまとめて運用するための、電源・空調・防犯が整った専用施設は？**

1. データセンター
2. オフィスビル
3. オンプレミス
4. クラウドストレージ
【正解】1
**【解説】** 24時間体制で安定運用される企業システムやクラウドの基盤。地震・停電に強い設備が求められます。

**Q7. 家電・センサー・自動車など、あらゆる「モノ」をインターネットに接続する技術の総称は？**

1. AI（人工知能）
2. RPA（業務自動化ロボット）
3. IoT（モノのインターネット）
4. AR（拡張現実）
【正解】3
**【解説】** スマート家電やコネクテッドカーなど、現実世界のデータをネット経由で収集・制御する基盤技術です。

**Q8. 4Gの次世代にあたる「超高速・低遅延・多数同時接続」が特徴のモバイル通信規格は？**

1. 3G
2. LTE
3. Wi-Fi6
4. 5G
【正解】4
**【解説】** 自動運転や遠隔医療など、リアルタイム性が必須の新サービスを支える通信規格です。

**Q9. アプリやサービスの機能を、他システムから呼び出して利用するための「窓口」となる仕組みは？**

1. GUI
2. SDK
3. CLI
4. API
【正解】4
**【解説】** 「LINEログイン」や「Google Maps連携」などはAPIを通じて実現。サービス間連携の基本技術です。

**Q10. データをクラウドに集約せず、現場の機器やその近くで処理することで通信遅延を減らす方式は？**

1. クラウドコンピューティング（集中処理）
2. エッジコンピューティング（端末側処理）
3. グリッドコンピューティング（分散計算）
4. メインフレーム（汎用大型機）
【正解】2
**【解説】** IoT機器や監視カメラなど、リアルタイム性が求められる場面で、データ発生源の近くで処理することで遅延と通信量を抑えます。

### 第3章：広告・分析編（数字を読み解く）

**Q21. 広告が1000回表示されるごとに料金が発生する課金方式は？**

1. CPC（クリック課金）
2. CPV（動画視聴課金）
3. CPA（成果獲得課金）
4. CPM（インプレッション課金）
【正解】4
**【解説】** 「Cost Per Mille（Mille=1000）」の略。認知拡大目的のディスプレイ広告でよく使われます。

**Q22. 投資した費用に対し、どれだけの「利益」を得られたかを示す経営指標は？**

1. ROAS（広告費用対効果）

3. ROI（投資利益率）
4. LTV（顧客生涯価値）
【正解】3
**【解説】** ROASが「売上」基準なのに対し、ROIは「利益」基準。広告以外の投資判断にも使われます。

**Q23. 1人の顧客が取引期間中にもたらす総利益を示す、サブスクで特に重視される指標は？**

1. ARPU（ユーザー平均単価）
2. LTV（顧客生涯価値）
3. CAC（顧客獲得コスト）
4. NPS（顧客推奨度）
【正解】2
**【解説】** 「Life Time Value」の略。継続率と単価が高いほど大きくなり、許容できる顧客獲得コストの目安になります。

**Q24. 一定期間にサイトを訪問した「重複を除いた人数」を示す指標は？**

1. PV（ページビュー）

**【解説】** 同じ人が3回訪問してもUUは1。実際にサイトに来た「人数」を把握できます。

**Q25. 広告が「何人にユニークに届いたか」を示す指標は？**

1. リーチ
2. フリークエンシー

**【解説】** インプレッションが延べ表示回数なのに対し、リーチは重複を除いた到達人数を表します。

**Q26. 「注意→興味→検索→行動→共有」というSNS時代の購買行動モデルは？**

2. SIPS

**Q27. 「30代女性で東京在住」のように、属性・地域・興味で配信対象を絞る広告手法は？**

**Q28. Googleが提供する、サイト訪問者の行動を計測・分析できる無料のアクセス解析ツールは？**
